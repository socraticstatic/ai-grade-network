Drop the font files here to restore the intended type:
  ATTAleckSans_Regular.woff2
  ATTAleckSans_Medium.woff2
  ATTAleckSans_Bold.woff2

The @font-face rules at the top of each *.dc.html already point at this
folder. Without them the pages fall back to Helvetica Neue / Arial and
render correctly - only the letterforms differ.
